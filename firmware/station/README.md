# Station firmware

Always-on LoRa receiver (single-channel or 8-channel concentrator): timestamping, heartbeat-due tracking, detecting missed heartbeats, local cluster detection, MQTT uplink with store-and-forward, health reporting, and autonomous local siren control.

See [ARCHITECTURE.md](../../docs/ARCHITECTURE.md) and [PROTOCOL.md](../../docs/PROTOCOL.md). **Status:** not started.
